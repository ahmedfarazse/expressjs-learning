# Express.js Route Parameters

This folder contains Express.js route parameter examples and practice exercises.

Route parameters allow dynamic values to be passed through URL paths and are commonly used to identify specific resources.

---

## Purpose

- Understand route parameters
- Learn how to use `req.params`
- Practice single route parameters
- Practice multiple route parameters
- Understand static and dynamic routes
