# Express.js Pagination

This folder contains Express.js pagination examples and practice exercises.

Pagination is used to divide large amounts of data into smaller pages and return a limited number of records for each request.

---

## Purpose

- Understand API pagination
- Learn how to use `page` and `limit` query parameters
- Practice reading query parameters with `req.query`
- Learn how to calculate the pagination starting position
- Practice using JavaScript `slice()`
- Understand pagination between controllers and services
