# Express.js Request Body

This folder contains Express.js request body examples and practice exercises.

Request bodies allow clients to send data to the server, commonly through POST requests using JSON.

---

## Purpose

- Understand request bodies
- Learn how to use `req.body`
- Learn how `express.json()` works
- Practice receiving JSON data
- Test POST requests using Postman
- Understand the difference between params, query, and body
