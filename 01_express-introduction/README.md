# Express.js Introduction

This folder contains my first Express.js server and basic route examples.

Express.js is a web framework built on top of Node.js. The code in this folder focuses on understanding the basics of Express.js and handling simple GET requests.

---

## Purpose

* Understand the basics of Express.js
* Learn how to create an Express application
* Practice creating GET routes
* Understand request and response objects
* Learn how to start an Express server
