# Express.js Sorting

This folder contains Express.js sorting examples and practice exercises.

Sorting is used to arrange API data according to a specific field and order using query parameters.

---

## Purpose

- Understand API sorting
- Learn how to use query parameters for sorting
- Practice JavaScript `sort()`
- Practice numeric sorting
- Practice string sorting with `localeCompare()`
- Learn ascending and descending sorting
- Understand sorting between controllers and services
