# REST Principles

This folder contains notes and reference material about REST principles and REST style API design.

The practical REST concepts have already been practiced throughout the Express.js learning journey, including HTTP methods, resource based URLs, route parameters, request handling, and status codes.

---

## Purpose

- Understand REST principles
- Understand resource based API design
- Review HTTP methods
- Understand REST style URL structure
- Understand stateless requests
- Review HTTP status codes
- Prepare for designing clean REST APIs
