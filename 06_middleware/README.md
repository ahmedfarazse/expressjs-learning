

# Express.js Middleware

This folder contains Express.js middleware examples and practice exercises.

Middleware functions run between incoming requests and route handlers and are used to process requests before generating a response.

---

## Purpose

- Understand Express.js middleware
- Learn `req`, `res`, and `next`
- Practice custom middleware
- Learn how to use `app.use()`
- Understand `express.json()` as middleware
- Practice request logging
