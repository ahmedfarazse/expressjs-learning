# Express.js Filtering

This folder contains Express.js filtering examples and practice exercises.

Filtering is used to return only the resources that match specific conditions provided through query parameters.

---

## Purpose

- Understand API filtering
- Learn how to use query parameters for filtering
- Practice using `req.query`
- Practice JavaScript `filter()`
- Learn how to filter by different fields
- Practice multiple and optional filters
- Understand filtering between controllers and services
